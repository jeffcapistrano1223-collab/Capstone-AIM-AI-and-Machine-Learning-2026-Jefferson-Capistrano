# Models

This directory is reserved for trained machine learning model artifacts.

Models evaluated in this project:

- Logistic Regression
- Decision Tree
- Random Forest
- XGBoost
- Regularized XGBoost

XGBoost was selected as the champion model based on the predefined
primary evaluation metric, PR-AUC.

Champion XGBoost test performance:

- Precision: 0.8462
- Recall: 0.8105
- F1 Score: 0.8280
- ROC-AUC: 0.9752
- PR-AUC: 0.8151

Random seed: 42
